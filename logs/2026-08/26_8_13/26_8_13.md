## 提示词示例

以“男婴｜发展”样例为例：

```text
12秒，竖屏9:16，写实家庭育儿示范。固定角色：男婴，浅色连体衣；
在铺有硬实垫子的地面，照护者全程近旁看护。镜头一：男婴清醒时
短暂俯卧并尝试抬头；镜头二：照护者轻声描述正在做的事；镜头三：
缓慢移动黑白图卡或红球让男婴追视。结尾回到安全仰卧睡眠画面。
旁白严格使用 voiceover；不在睡眠时俯卧、不让宝宝独处、不快速
晃动玩具，不暗示必须完成或延迟即诊断。
```

提示词继续沿用三镜头时间轴、角色一致性锚点、来源引用、负面约束和安全审查要求，避免把单次表现表达成硬性达标或诊断结论。

## 脚本代码摘录

以下代码来自 `batch_seedance_videos.py` 的分镜提示词组装逻辑，负责把结构化分镜转换成可提交给视频模型的执行单：

```python
def render_seedance_prompt(manifest, record):
    # 用“月龄 + 维度”定位对应的三镜头模板
    key = f"{record['ageMonths']}:{record['dimension']}"
    template = manifest["storyboardTemplates"][key]

    lines = [
        "【Seedance分镜执行单】",
        "输出：竖屏 9:16，12 秒，24fps；严格按时间轴执行。",
        f"目标：{record['title']}；年龄：{record['ageLabel']}。",
        f"角色连续性：{record['consistencyAnchor']}",
        f"视觉与动作要求：{record['seedancePrompt']}",
        "【时间轴】",
    ]
    # 把每个镜头的动作和连续性约束写入最终 Prompt
    for shot in template["shots"]:
        lines.append(
            f"{shot['time']}｜{shot['shot']}｜动作：{shot['action']}｜"
            f"连续性：{shot['continuity']}"
        )
    return "\n".join(lines)
```
