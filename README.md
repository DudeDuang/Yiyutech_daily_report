# 实习日报 📓

记录我的实习日常：每日完成、学习收获、问题解决。

> ⚠️ 本仓库为**公开仓库**，请遵守以下规则：
>
> - ❌ 不写公司名称、内部项目名、同事姓名
> - ❌ 不写内部系统地址、业务数据、未公开的产品信息
> - ❌ 不提交任何公司代码、截图、密钥
> - ✅ 只写通用的学习收获、技能总结、个人思考

## 目录结构

```
daily_report/
├── README.md                  # 本文件
├── LICENSE                    # 内容许可（CC BY 4.0）
├── .gitignore
├── templates/
│   └── daily-template.md      # 日报模板
├── logs/                      # 按月 > 按天存放
│   └── 2026-08/
│       └── 26_8_12/
│           ├── 26_8_12.md     # 当天日报
│           └── 参考图/        # 当天素材
├── new-day.sh                 # 一键创建当天日报
└── push-day.sh                # 提交并推送
```

## 每日流程

```bash
# 1. 创建今天的日报（自动套用模板，已存在会跳过）
./new-day.sh

# 2. 编辑生成的日志文件
#    logs/2026-08/26_8_12/26_8_12.md

# 3. 下班前提交并推送
./push-day.sh
```
